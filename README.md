# Random Quote Generator

**Автор:** Грекова Диана

## Описание
Простая программа, которая показывает случайные мотивирующие цитаты.  
Можно:
- Нажать кнопку и получить случайную цитату
- Посмотреть историю всех цитат, которые ты сгенерировал
- Отфильтровать цитаты по автору или теме
- Добавить свою цитату (текст, автор, тема)
- Всё сохраняется в JSON файлы (история и твои добавленные цитаты)

## Как запустить
1. Установи Python (если нет) — скачай с python.org
2. Сохрани файл `main.py` в пустую папку
3. Открой терминал / командную строку в этой папке
4. Напиши: `python main.py`

## Примеры использования

**Пример 1:** Просто получить случайную цитату  
Нажимаешь кнопку «Сгенерировать цитату» — появляется цитата.

**Пример 2:** Посмотреть только цитаты Махатмы Ганди  
Выбираешь в фильтре «Автор» → Махатма Ганди → нажимаешь кнопку — покажутся только его цитаты.  
История тоже станет показывать только его цитаты.

**Пример 3:** Добавить свою цитату  
Заполняешь три поля (текст, автор, тема) → нажимаешь «Добавить цитату» → она появляется в главном списке.
